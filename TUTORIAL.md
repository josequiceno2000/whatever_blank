## Git Commands
- git init
- git status
- git add [filename]
- git commit (-m) ("")
- git remote add origin <PASTE_YOUR_GITHUB_URL_HERE> **first time only
- git push
- git log (--oneline)

## Conventional Commits
- "(feat, chore, docs, fix): (Message)"
  - feat: new feature
  - chore: building out 
  - docs: writing out something in MD file
  - fix: bugs
- present tense imperative

## Say WHY, not HOW or the WHAT
